# Эксплуатация

Этот раздел станет runbook для production-инсталляции.

## Наблюдаемость

Минимальный набор:

- readiness/liveness системных компонентов;
- длительность provisioning попытки;
- число сессий по состояниям;
- частота workspace-auth проверок и доля отказов;
- результаты checker;
- ошибки Kubernetes API и Clabernetes;
- CPU/RAM/storage по namespace попыток;
- зависшие terminal/capture процессы.

## Обновления

- production использует фиксированные SemVer-теги;
- `latest` допустим только в демонстрационном контуре;
- Helm upgrade сначала проходит kind E2E;
- миграции базы выполняются отдельным контролируемым job;
- должен существовать описанный rollback.

## Резервное копирование

Нужно определить RPO/RTO и отдельно сохранять:

- базу CMS;
- отчёты и notebook;
- конфигурацию окружения без открытых секретов;
- audit log и итоговые оценки.

> **Нужна иллюстрация:** dashboard эксплуатации с provisioning latency, активными попытками, ошибками checker и потреблением ресурсов.
