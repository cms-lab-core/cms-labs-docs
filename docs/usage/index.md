# Как запустить CMS Labs

Этот раздел предназначен для пользователей готовой платформы: студентов, преподавателей и администраторов демонстрационных стендов.

## Доступные варианты

| Вариант | Когда выбирать | Что потребуется |
| --- | --- | --- |
| [GitHub Codespaces](codespaces.md) | пройти одну лабораторную без локальной установки | GitHub-аккаунт и Codespaces quota |
| [Локальный kind](kind.md) | воспроизвести полный контур на своём компьютере | Docker и ресурсы для локального Kubernetes |
| [Kubernetes-кластер](kubernetes.md) | предоставить платформу группе пользователей | существующий кластер, DNS, TLS и storage |

Docker Compose здесь не является пользовательским вариантом: он не воспроизводит namespace попытки, Clabernetes, workspace proxy и сервисы лаборатории. Он применяется только внутри разработки компонентов.

> **Нужна иллюстрация:** три карточки выбора — Codespaces для одного пользователя, kind для локального полного стенда и Kubernetes для общего сервиса.
