# Глоссарий

**Попытка** — запись учебной активности пользователя в CMS.

**Сессия** — работающий Kubernetes-контур конкретной попытки.

**Лабораторная работа** — Git-репозиторий с заданием, topology и конфигурацией сервисов.

**Workspace** — доступная студенту среда: JupyterLab, terminal и связанные инструменты.

**Clabgate** — control plane лабораторных сессий и шлюз доступа к workspace.

**Clabernetes** — оператор запуска Containerlab-топологий в Kubernetes.

**Checker** — сервис автоматической проверки задания.

**Grant** — короткоживущий код, подтверждающий право открыть сервис сессии.

**Capture** — сервис управляемого захвата сетевого трафика в PCAP.

**LTI** — протокол интеграции учебной платформы с LMS, например Moodle.
