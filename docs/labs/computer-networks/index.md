## «Масштабируемые корпоративные сети» в УрФУ

Этот курс открывается из назначенного преподавателем элемента Moodle или из каталога CMS Labs по ссылке преподавателя. Для версии на Kubernetes выбирайте карточки с пометкой **(c9s)**, если именно эту версию назначил преподаватель.

| Работа | Тема |
| --- | --- |
| [1.0](lab-001.md) | Создание и настройка небольшой сети |
| 1.1 | Статические маршруты IPv4 |
| 2.1 | DHCPv4 и ретрансляция |
| 2.2 | DHCPv6 и SLAAC |
| 3 | HSRP |
| 4 | OSPF для одной области |
| 5.0 | NAT для IPv4 и сетевое администрирование |
| 5.2 | Контрольная работа по маршрутизации IPv4 и IPv6 |
| 6 | Ansible, резервное копирование и настройка |
| 7 | Пакетные фильтры ACL |

Задания и индивидуальные варианты находятся во вкладке **«Задание»**. Порядок сдачи описан в [инструкции для студента](../../usage/student.md).
