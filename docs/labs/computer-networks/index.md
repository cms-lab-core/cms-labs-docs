# Курс «Компьютерные сети»

Курс знакомит с базовыми сетевыми протоколами и конфигурацией сетевых устройств в воспроизводимой виртуальной среде.

## Формат работы

1. Студент выбирает лабораторную в каталоге CMS.
2. Платформа создаёт изолированную сессию и сетевую топологию.
3. Задание открывается в JupyterLab.
4. Команды выполняются через встроенные терминалы узлов.
5. Автоматические проверки показывают прогресс и объясняют ошибки.
6. После завершения сохраняются отчёт, журнал и оценка.
